# ADVISOR Website

This is the Quarto website scaffold for ADVISOR: Advanced Detection Via Integrated Sensors for Operational Resilience.

## Local preview

```bash
quarto preview
```

## Render site

```bash
quarto render
```

The rendered site will be created in the `docs/` folder.

## Publish using GitHub Pages

1. Create a GitHub account or organization named `lab-advisor`.
2. Create a public repository named `lab-advisor.github.io`.
3. Upload these files to the repository.
4. In GitHub, go to Settings > Pages.
5. Set the source to deploy from the `main` branch and `/docs` folder.
6. Visit `https://lab-advisor.github.io`.

## Edit content

Edit the `.qmd` files, then run:

```bash
quarto render
```

Commit and push the updated files to GitHub.
